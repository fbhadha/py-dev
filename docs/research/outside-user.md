# Research: the outside user and the remembered literal, for 0.13.0

Verified 2026-09-25. The question: two failure modes kept damaging codebases built with the agent. It typed values, paths, keys and signatures it remembered from earlier in its context instead of reading the file; and when it tested an agent it acted as the author, feeding the agent the words it knew would work. What does the literature say about simulated users, what does Google ADK already ship, and what can each harness enforce? The rules are in `agents/python-dev.md` (section 2), `skills/py-build/SKILL.md` and `skills/pack-adk/SKILL.md` (the outside user); decision 55 in `docs/design/python-dev-agent.md` records what was decided. This note holds the sources and what was run.
